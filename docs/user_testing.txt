Since you're building an **ERP**, don't think of user testing as "click every button." Think of it as **validating business workflows**.

I recommend this order for **every future module** as well.

# Phase 14 — Final Business Workflow

Run the complete ERP workflow:

```
Customer
      ↓
Customer Interaction
      ↓
Multiple Follow-ups
      ↓
Convert to Enquiry
      ↓
Customer Service
      ↓
Pricing
      ↓
Job
```

Verify:

* [ ] No data loss
* [ ] Correct status transitions
* [ ] Audit trail maintained
* [ ] Permissions respected at every step

---

## My recommendation

Create a **Master User Testing Template** with this checklist and reuse it for every Bonzer ERP module (Customers, Interactions, Enquiries, Pricing, Jobs, Accounts, etc.). The specific business tests will change, but the overall testing framework stays the same, giving you a consistent definition of "Done" for every phase.
